## What I Learned

1. Define and call functions, understand parameters vs arguments
2. Use default arguments, keyword arguments, `*args`, and `**kwargs`
3. Return single and multiple values from functions
4. Understand variable scope: local, global, and the `global` keyword
5. Write and use `lambda` functions
6. Use built-in functional tools: `map()`, `filter()`, `zip()`, `enumerate()`, `sorted()`, `len()`, `sum()`, `min()`, `max()`
7. Import and use modules and packages (`import`, `from...import`, `as`)
8. Use standard library modules: `math`, `random`, `datetime`, `os`, `sys`
9. Understand virtual environments (`venv`) and `pip`
10. Organize your own code into reusable modules
